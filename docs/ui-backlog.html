Each task keeps the spec as it was written; what we add is whether it has shipped and the commit that shipped it, so the two can always be compared.

Rules that apply to every task

  • Never replace a choice the customer made. If it becomes invalid, keep it visible with "Not available" and let them pick again.
  • Unknown is not impossible. A loading or failed check never shows "Not available" or hides an option.
  • No supplier live call before "Check price & availability". Home, Results and the hotel page before the check read cache APIs only.
  • Ready-made English strings are in src/i18n/locales/en/common.json. Dutch copies are needed for new ones.
